Logi-DS (Nintendo DS)

Only use ROMs that you legally own. Powered by EmulatorJS (melonDS / DeSmuME cores).
Note: NDS emulation in the browser is experimental and may run slower than other systems. DS support does not work reliably on the standard EmulatorJS page. This dedicated page uses the melonDS core for the best compatibility available in-browser.

Drop a legally-owned .nds ROM below and the emulator runs locally in your browser. Nothing is uploaded.

Drag your .nds ROM here, or click to browse
Tips for Nintendo DS emulation in the browser:
  • I recommend using a browser like chrome, edge to run it.
  • It could also end up not working like EmulatorJS so no promises, but this is dedicated for it.
  • Some games may run slowly DS emulation in-browser.
  • Touch screen input maps to mouse clicks on the bottom (lower) screen area.
  • Use the emulator's built-in menu to configure controls, save states, and screen layout.
  • ROM data stays entirely in your browser; nothing is sent to any server.

Why not melonDS directly? The official melonDS is a desktop C++ app with no public web demo yet (a WASM port is in progress by the community but not officially released). This page uses EmulatorJS's melonDS core, which is the best browser-based option currently available.
